# shinobi-hypr

Entorno Arch Linux + Hyprland automatizado con barra dual dinamica, colores automaticos con `wallust` y **Shinobi Dashboard** interactivo con `eww`.

## Instalacion automatica en un solo comando (sin descargar nada)

```bash
bash <(curl -fsSL [https://raw.githubusercontent.com/Dervi-RMX/shinobi-hypr/main/install.sh](https://raw.githubusercontent.com/Dervi-RMX/shinobi-hypr/main/install.sh))
```

## Atajos clave

* **Super + Z** / **Alt + Z** / **Clic izquierdo en el icono de Arch**: Abre o cierra el **Shinobi Dashboard** (tambien se cierra haciendo clic fuera).
* **Super + B**: Alterna entre barra lateral y barra superior.
* **Super + W**: Selector de wallpapers con colores automaticos.
